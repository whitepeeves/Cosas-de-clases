¿Qué problema resuelve un entorno virtual?

El entorno virtual resuelve los problemas de conflictos de dependencias y versiones entre distintos proyectos

¿Qué crea realmente python -m venv .venv?

Al hacer eso python crea un nuevo directorio que se llama .venv , que hace una ruta de carpetas aislada y que hace una copia limpia de las herramientas que gestionan los paquetes

¿Dónde se guardan las librerías que instalamos dentro de él?

se guardan fisicamente en la carpeta de paquetes. Cada vez que instalas desde la terminal, se descargan desde internet y crean una nueva subcarpeta

¿Qué ocurre realmente cuando lo “activamos”?

Encenderlo no modifica nada ni utiliza nada complejo, solo modifica la variable "path" y crea tambien el entorno virutal de _ENV

¿Es obligatorio activarlo para utilizarlo?

no, no es necesario
